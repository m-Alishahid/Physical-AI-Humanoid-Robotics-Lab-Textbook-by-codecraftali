**A complete textbook for Physical AI & Humanoid Robotics course** - Built for the Panaversity Hackathon using AI-native development tools.

## 🎯 Overview

This textbook provides comprehensive coverage of Physical AI and Humanoid Robotics, from ROS 2 fundamentals to advanced VLA models. Designed for the 13-week course curriculum, it serves as both a learning resource and a demonstration of AI-assisted technical content creation.

## 🏗️ Build Methodology

This project demonstrates **AI-native development** using:

1. **Spec-Kit Plus**: Specification-driven development workflow
   - `sp.specify` → Requirements definition
   - `sp.plan` → Implementation strategy
   - `sp.implement` → Code generation

2. **Claude Code**: AI-assisted content creation
   - Technical content generation
   - Code examples and explanations
   - Consistent formatting

3. **Docusaurus**: Professional documentation framework
   - Modular content organization
   - SEO optimization
   - Responsive design

## 🚀 Getting Started

### Prerequisites
- Node.js 18 or higher
- npm or yarn
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/Physical-AI-Humanoid-Robotics-Lab-Textbook-by-codecraftali.git

# Navigate to project directory
cd Physical-AI-Humanoid-Robotics-Lab-Textbook-by-codecraftali

# Install dependencies
npm install
# or
yarn install
Local Development
bash
# Start development server
npm start
# or
yarn start
The site will be available at http://localhost:3000

Build for Production
bash
# Create production build
npm run build
# or
yarn build

# Serve the build locally
npm run serve
# or
yarn serve
